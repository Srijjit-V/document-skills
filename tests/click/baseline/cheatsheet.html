Click Cheat Sheet

Click 8.5+ · pip install click · import click

Minimal command

@click.command()
@click.argument("name")
@click.option("--count", "-c", default=1,
    show_default=True, help="Repeats.")
def hello(name, count):
    """Greet NAME."""   # = --help text
    for _ in range(count):
        click.echo(f"Hello {name}")

if __name__ == "__main__":
    hello()

Groups & subcommands

@click.group()
@click.option("-v", "--verbose", count=True)
@click.pass_context
def cli(ctx, verbose):
    ctx.ensure_object(dict)
    ctx.obj["verbose"] = verbose

@cli.command()       # name "sync"
@click.pass_obj      # gets ctx.obj
def sync(obj): ...

cli.add_command(other, name="other")
invoke_without_command=TrueGroup runs alone; check ctx.invoked_subcommand
chain=Truecli a b c runs several
@cli.result_callback()Post-process return values
@click.command("my-name")Override name

_ becomes -: def dry_run → dry-run.

Validation callback

def check(ctx, param, value):
    if value % 2:
        raise click.BadParameter("even only")
    return value

@click.option("--n", type=int,
              callback=check)

is_eager=True + expose_value=False: process first, keep out of function args (how --version works).

Testing

from click.testing import CliRunner

def test_sync(tmp_path):
    r = CliRunner().invoke(
        cli, ["sync", str(tmp_path)],
        env={"APP_TOKEN": "t"}, input="y\n")
    assert r.exit_code == 0, r.output
    assert "done" in r.stdout
    # also r.stderr, r.output

r.exception holds an uncaught exception. Use tmp_path; isolated_filesystem() is deprecated in 8.5.

Packaging & completion

# pyproject.toml
[project.scripts]
mytool = "mytool.cli:cli"

Completion (bash, zsh, fish, powershell):
_MYTOOL_COMPLETE=zsh_source mytool > ~/.mytool-complete.zsh, then source it from your shell rc.

Gotchas

  • Parameter names must match function args (--dry-run → dry_run).
  • Only one nargs=-1 argument per command; it yields () when nothing is passed.
  • default on a multiple=True option must be a list/tuple.
  • ctx.obj is None until set: call ctx.ensure_object(dict).
  • Use click.echo, not print(): it respects CliRunner capture and strips color when piped.
