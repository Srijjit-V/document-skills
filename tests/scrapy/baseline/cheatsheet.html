Spider

import scrapy
class Q(scrapy.Spider):
    name = "q"
    allowed_domains = ["example.com"]
    start_urls = ["https://example.com/"]
    custom_settings = {"DOWNLOAD_DELAY": 1}

    async def start(self):  # optional
        yield scrapy.Request(self.start_urls[0])

    def parse(self, response):  # or async def
        for q in response.css("div.quote"):
            yield {"text": q.css("span::text").get()}
        yield from response.follow_all(
            css="a.next", callback=self.parse)

Generic: CrawlSpider + Rule(LinkExtractor(allow=r"/p/"), callback="parse_item", follow=True), SitemapSpider, XMLFeedSpider, CSVFeedSpider.

Items & Pipelines

class P(scrapy.Item):
    name = scrapy.Field()

class Clean:
    def process_item(self, item):
        return item   # raise DropItem to discard

ITEM_PIPELINES = {"myproj.pipelines.Clean": 300}

Lower number runs first. Items: dict, dataclass, attrs, scrapy.Item (via ItemAdapter). Media: FilesPipeline, ImagesPipeline.

From a script

from scrapy.crawler import AsyncCrawlerProcess
from scrapy.utils.project import get_project_settings
p = AsyncCrawlerProcess(get_project_settings())
p.crawl("q")
p.start()  # blocks

Data flow

Spider start() → spider mw → Engine → Scheduler (dupefilter) → downloader mw → Downloader/handlers → response → downloader mw → spider mw → callback → items → Pipelines · requests → Scheduler
