# Start here: Scrapy

Scrapy is a Python framework for crawling websites and extracting structured data. You write a spider class that says which URLs to fetch and how to parse each response; Scrapy handles scheduling, concurrency, retries, deduplication, and exporting the items. This checkout is version 2.19.0 (`scrapy/VERSION`) and needs Python 3.11+ (`pyproject.toml`).

None of the commands below were executed while writing this page (installing packages was not allowed in the writing environment). Each one was checked against the source, and the file is cited.

Where things live:

| Path | What lives there |
|---|---|
| `scrapy/cmdline.py` | `scrapy` CLI entry point (`execute()`, line 184) |
| `scrapy/commands/` | One module per CLI command |
| `scrapy/core/` | Engine, scheduler, downloader, scraper: the crawl loop |
| `scrapy/downloadermiddlewares/`, `scrapy/spidermiddlewares/` | Built-in middlewares (retry, redirect, cookies, robots.txt, offsite, depth) |
| `scrapy/settings/default_settings.py` | Every built-in setting and its default |
| `scrapy/templates/` | Files generated by `startproject` and `genspider` |
| `tests/`, `tests/mockserver/` | pytest suite and the local HTTP server tests crawl against |
| `docs/` | Sphinx sources for docs.scrapy.org |

## Day 1: run a spider

Install from the checkout and create a project `[unverified]`:

```bash
pip install -e .
scrapy startproject quotes
cd quotes
scrapy genspider toscrape quotes.toscrape.com
```

`genspider` writes `quotes/spiders/toscrape.py` from `scrapy/templates/spiders/basic.tmpl`. Fill in `parse`:

```python
import scrapy


class ToscrapeSpider(scrapy.Spider):
    name = "toscrape"
    allowed_domains = ["quotes.toscrape.com"]
    start_urls = ["https://quotes.toscrape.com/"]

    def parse(self, response):
        for q in response.css("div.quote"):
            yield {"text": q.css("span.text::text").get(),
                   "author": q.css("small.author::text").get()}
        yield from response.follow_all(css="li.next a", callback=self.parse)
```

Run it and write items to a file `[unverified]`:

```bash
scrapy crawl toscrape -O quotes.jsonl
```

A callback yields two kinds of objects: dicts (or other items), which go to the item pipelines and feed exports, and `Request` objects, which go back to the scheduler. To send custom first requests, define `async def start(self)` (added in 2.13, `scrapy/spiders/__init__.py:199`) instead of `start_urls`.

## Commands you will use

| Command | Does | Needs project |
|---|---|---|
| `scrapy crawl NAME -O out.json` | Run a spider; `-O` overwrites, `-o` appends | yes |
| `scrapy runspider file.py` | Run a spider file without a project | no |
| `scrapy shell URL` | Interactive console with `response` loaded | no |
| `scrapy parse URL --spider NAME -c parse_item` | Run one callback on one URL, print results | yes |
| `scrapy fetch --curl 'curl ...'` | Fetch a request built from a curl command | no |
| `scrapy genrequest 'curl ...'` | Print the `Request(...)` code for a curl command | no |
| `scrapy check NAME` | Run the spider's contracts (docstring tests) | yes |
| `scrapy settings --get NAME` | Print the resolved value of a setting | no |

Global options on every command (`scrapy/commands/__init__.py:129`): `-s NAME=VALUE` sets a setting, `-a NAME=VALUE` passes a spider argument (crawl, parse, runspider), `-L INFO` sets the log level, `--pdb` opens a debugger on logged exceptions.

## How a request flows

1. The engine (`core/engine.py:179`) pulls requests from `Spider.start()` and hands them to the scheduler.
2. The scheduler (`core/scheduler.py:140`) drops duplicates through `RFPDupeFilter` unless `dont_filter=True`, then queues the rest by priority.
3. Requests pass through downloader middlewares, then a download handler chosen by URL scheme (`DOWNLOAD_HANDLERS_BASE`, `default_settings.py:321`).
4. The response comes back through the downloader middlewares, then the scraper (`core/scraper.py:142`) runs spider middlewares and your callback.
5. Yielded items go through `ITEM_PIPELINES`; yielded requests return to step 2.

Middlewares, pipelines, and extensions are ordered dicts of `{"import.path": order}`; lower numbers run first for outgoing requests and for items.

## Settings

Settings resolve by priority (`scrapy/settings/__init__.py:31`): default 0 < command 10 < addon 15 < project 20 < spider 30 (`custom_settings`) < command line 40 (`-s`). Defaults worth knowing:

| Setting | Built-in default | `startproject` template |
|---|---|---|
| `ROBOTSTXT_OBEY` | `False` | `True` |
| `CONCURRENT_REQUESTS_PER_DOMAIN` | 8 | 1 |
| `DOWNLOAD_DELAY` | 0 | 1 |
| `CONCURRENT_REQUESTS` | 16 | 16 |
| `RETRY_TIMES` | 2 (3 attempts in all) | unchanged |
| `DOWNLOAD_TIMEOUT` | 180 s | unchanged |
| `LOG_LEVEL` | `"DEBUG"` | unchanged |
| `TWISTED_REACTOR` | `AsyncioSelectorReactor` | unchanged |

A spider run outside a project (`runspider`, or a script without `get_project_settings()`) gets the built-in column, so it ignores robots.txt and runs eight requests at once per domain.

## Gotchas

- Non-2xx responses never reach your callback: `HttpErrorMiddleware` drops them. Allow codes with `HTTPERROR_ALLOWED_CODES` or `meta={"handle_httpstatus_list": [404]}`.
- Repeated URLs are silently filtered. Pass `dont_filter=True` when a revisit is intended; `start_urls` requests already set it.
- `allowed_domains` takes domains (`"example.com"`), not URLs. Subdomains are allowed.
- `-o items.json` on an existing file appends a second JSON array and breaks the file. Use `-O`, or the `.jsonl` format for appends.
- Spider `name` is required and must be unique per project; the loader warns on duplicates and keeps one.

## Run Scrapy from a script

Use `AsyncCrawlerProcess` (`scrapy/crawler.py:1052`), the class the CLI uses:

```python
from scrapy.crawler import AsyncCrawlerProcess

process = AsyncCrawlerProcess(settings={"FEEDS": {"items.json": {"format": "json"}}})
process.crawl(ToscrapeSpider)
process.start()  # blocks until the crawl ends
```

## Contribute

Read `AGENTS.md` and the contributing guide first. Before a pull request `[unverified]`:

```bash
pre-commit run --all-files
tox -e mypy && tox -e pylint
tox -e py -- tests/test_command_crawl.py   # args after -- go to pytest
```

Tests crawl against `tests/mockserver/`, never the live web, and use `example.com` domains. Build components in tests with `scrapy.utils.misc.build_from_crawler()`. Prefix new internal names with `_`. Do not edit `docs/news.rst`; release notes are written at release time.
