HTTPie CLI Cheat Sheet

http [flags] [METHOD] URL [ITEM …] · v3.2.4 · also https, httpie

Basics

http pie.dev/getGET (default when there's no body)
http pie.dev/post a=1POST JSON (data present → POST)
http PUT pie.dev/put a=1Explicit method
http :3000/x→ localhost:3000/x
https example.orghttps:// by default
http --offline URL a=1Print the request, don't send it

Request items

H:vHeader
H; · H:Empty header · remove default header
H:@fileHeader value read from a file
q==v · q==@fQuery param (value or file)
k=vString field
k:=jsonRaw JSON: n:=1 ok:=true
k=@f · k:=@f.jsonField read from a file (text / JSON)
f@path;type=mFile upload (multipart)
a[b][]=x a[c]:=1Nested JSON
@body.jsonFile contents as the body
'a\==b'Escape a separator

Request body

-j (default)JSON object
-fForm (multipart if files)
--multipartAlways multipart (--boundary)
--raw 'txt'Raw body string
cmd | http POST URLBody from stdin
-x · -xxDeflate · forced
--chunkedChunked encoding

Output

-p HBhbmReq Hdr/Body, resp hdr/body, meta
-h · -b · -mResponse headers · body · meta
-v · -vvRequest + response (+meta)
--all · -P WHATShow redirect hops / what to print for them
-q · -qqQuiet · also hide warnings
-SStream by line (tail -f)
-o FILEWrite output to a file

Defaults: hb on a TTY · b when piped · HB with --offline

Formatting

--pretty=allall · colors · format · none
-s monokaiColor style (default auto)
--unsortedDon't sort keys/headers
--format-options=json.indent:2,xml.indent:4
--response-mime=Force formatter type
--response-charset=Force display encoding

Download

http -d URLSave to a file (name auto-detected)
-d -o f.zipExplicit filename
-dco f.zipResume (needs -o)

-d implies -F; progress bar on stderr.

Auth

-a user:passBasic (-a user prompts)
-A digest -a u:pDigest
-A bearer -a TOKENBearer token
--ignore-netrcSkip ~/.netrc

Sessions

--session=devNamed session, per host (headers, cookies, auth)
--session=./s.jsonSession at an explicit path
--session-read-only=devUse but don't save
httpie cli sessions upgrade-allMigrate format

Network / TLS

-FFollow redirects (max 30)
--max-redirects=NRedirect limit
--timeout=5Seconds
--proxy=https:http://h:psocks5 OK; env vars honored
--verify=no|ca.pemTLS verification
--cert c.pem --cert-key kClient certificate
--ssl=tls1.2 · --ciphersTLS version · ciphers
--path-as-isKeep /../ in the URL
--default-scheme=httpsScheme when the URL has none
--no-FLAGUnset a default/config flag

Scripting & exit codes

http -I --check-status --timeout=3 URL
-I (ignore stdin) stops cron jobs and scripts from hanging

0OK4HTTP 4xx*
1Error5HTTP 5xx*
2Timeout6Too many redirects
3HTTP 3xx* (no -F)7Plugin error
* with --check-status130Ctrl-C

Config

$HTTPIE_CONFIG_DIR → %APPDATA%\httpie → ~/.httpie → ~/.config/httpie

config.json: {"default_options": ["--style=fruity"], "plugins_dir": "…"}

Manager (httpie)

httpie cli plugins install XAlso: list / upgrade / uninstall
httpie cli check-updatesCheck for a new version
httpie cli export-argsExport the CLI spec as JSON
