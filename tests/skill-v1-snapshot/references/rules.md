## Edge cases
- **The user wants long.** A spec or design doc can run long. Raise the budget and keep the other rules. Length bias is about padding, not depth.
- **Agents read it too** (llms.txt, CLAUDE.md, AGENTS.md). The same rules apply: a one-line summary first, flat structure, explicit names and paths. For `llms.txt` follow [llmstxt.org](https://llmstxt.org/): H1, `>` summary, H2 link lists, `## Optional`.
- **Repetition.** Repeat a fact when it saves the reader a jump to another page ("ARID", Write the Docs). Don't restate a paragraph inside the same doc.
- **Bold for scanning** is endorsed by NN/g. Overuse is the problem: one bolded keyword per ~100 words, not a bold label on every line.
